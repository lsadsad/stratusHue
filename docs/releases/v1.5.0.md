## Validate Mode (Early Preview)

A new **Validate** tab introduces Design Lint — scan your current page for style inconsistencies and fix them without leaving Figma.

### What it checks
- **Fill colors** — flags fills not linked to a shared style
- **Stroke colors** — flags strokes not linked to a shared style
- **Text styles** — flags text layers not using a shared text style
- **Effects** — flags effects (shadows, blurs) not linked to a shared style
- **Border radius** — flags corner radius values outside your allowed set

### How it works
- **Three scan scopes** — scan your current selection, emoji-tagged layers, or the entire page
- **Batch actions** — Select All, Fix All, Ignore All for fast triage
- **Click to select** — click any error to jump to and select the offending layer in Figma
- **Auto-rescan** — the scan re-runs automatically when you make changes (with a 2-second debounce)
- **Settings panel** — toggle check categories on/off, configure allowed border radius values, add layer name patterns to skip
- **Large file gate** — page-scope scans warn before scanning files with 5,000+ nodes
- **Cancellable** — long-running scans can be cancelled mid-flight

Validate mode is a preview. More check types are on the way — token audit, component compliance, and a readiness check are planned for future releases.
