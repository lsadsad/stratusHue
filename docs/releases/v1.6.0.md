# stratusHue v1.6.0

Released 2026-09-XX

---

## Validate Mode Has Been Withdrawn

The **Validate** tab shipped in v1.5.0 as an early preview. It is not in this release.

Design Lint checked style consistency by walking the page and comparing each node against your shared styles. That worked, but it could only ever answer "does this match a style?" — not "is this file ready to hand off?", which is the question the checks were meant to build toward.

The check layer is being rebuilt on **recipes**: a team-configured description of what a file should contain. The three checks promised in the v1.5.0 notes — token audit, component compliance, and readiness — are all recipe-driven, and each is blocked on the recipe schema rather than on lint internals. Rather than keep a preview in the UI that was going to be replaced wholesale, it has been removed until the recipe layer exists.

**If you used Design Lint:** there is no in-plugin replacement in this release. Nothing else changed about how your files behave — the checks were read-only.

Everything Navigate gained in v1.5.0 — recursive emoji tagging, sticky section headers, header polish — is still here.

## Date Tagging

The date button is now configurable from Settings.

- **Format** — numeric (`09.07`) or alpha (`Sep 07`)
- **Position** — prefix or suffix
- **Suffix separator** — suffixed dates are joined with `-` so they read cleanly against the page name
- Re-tagging a page that already has a date now **replaces** it instead of appending a second one

---

## Settings Overlay

A layout and accessibility pass:

- Sections are grouped under titled headings with a clearer visual hierarchy
- Controls are reachable and labelled for assistive technology
- The overlay fills its container rather than floating at a fixed size, so it works at both plugin widths

---

## Navigate Fixes

- **Anchors panel** — an expanded anchors list grows to its natural height instead of being clipped
- **Bookmarks** — a bookmark that fails to save now tells you, rather than disappearing silently
- **Sizing modes** — the Fill and Hug icons now swap correctly when you cycle a layer
- **Sizing cycle order** — cycles Fixed → Fill → Hug

## What's Coming

- **Recipe schema** — the team-configured file description the checks below are built on
- **Token audit** — verify style and variable coverage across your file
- **Component check** — flag detached instances and outdated library versions
- **Readiness check** — one-scan handoff validation
- **Scaffold mode** — generate file structure from a recipe
