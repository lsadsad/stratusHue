# 🌈 stratusHue

A Figma plugin that uses color emojis and smart bookmarking to help designers organize and navigate complex design files.

stratusHue works across **Figma**, **FigJam**, and **Slides** . It supports the entire team—developers, product managers, QA, and creators—aligning with Figma's goal of making design accessible.

## ✨ Features

### ⏪ Navigation History
- **Back/Forward**: Navigate through your selection history
- **New Page**: Quickly create a new page

### 🎨 Smart Color Coding
- **Layer & Page Emoji Support**: Add color emojis to layers and pages
- **Context-Aware Selection**: Automatically switches between square emojis for layers and circle emojis for pages
- **Intelligent Replacement**: Automatically replaces existing color emojis while preserving position
- **Visual Mode Indicator**: Shows current mode (Layer or Page) to indicate context
- **Smart Detection**: Automatically detects whether you're working with layers or pages based on selection

### 📅 Date Tagging
- **One-Click Date**: Add today's date to selected layer names or the current page title
- **Auto-Replacement**: Detects and replaces existing dates to keep things current
- **Consistent Format**: Uses a clear, consistent pattern for page titles

### 📄 Page Title Management
- **Canonical Titles**: Builds page titles with a consistent token order
- **Indent/Outdent**: Adjust page title hierarchy with indent controls
- **Normalization**: Cleans up invisible characters and spacing so titles remain uniform

### 🔖 Intelligent Bookmarking (Anchors)
- **One-Click Bookmarks**: Save important design elements with a single click
- **Page Context**: Each bookmark shows which page it's located on
- **Smart Navigation**: Jump directly to bookmarked elements across pages
- **Drag & Drop Reordering**: Organize your bookmarks by dragging them
- **Resync**: Refresh anchor names and page locations after manual changes

### 🕹️ Movement & Zoom Controls
- **Arrow Key Movement**: Move selected elements by 1px (or 8px with Shift)
- **Resize Mode**: Hold Ctrl while moving to resize elements
- **Duplicate Mode**: Hold Alt while moving to duplicate elements
- **Zoom Controls**: Zoom in, zoom out, zoom to 100%, and zoom to selection

### 🗂️ Layer Hierarchy Navigation
- **Enter/Exit Containers**: Navigate into and out of groups and frames
- **Sibling Navigation**: Move between sibling layers with Previous/Next
- **Collapse Containers**: Tidy up the layer panel by collapsing containers
- **Layer Ordering**: Bring forward/backward or bring to front/send to back

### 📐 Sizing Modes
- **Width Cycling**: Toggle between Hug, Fill, and Fixed width modes
- **Height Cycling**: Toggle between Hug, Fill, and Fixed height modes

### 💅 User Experience
- **Collapsible Interface**: Clean, organized UI with expandable sections
- **Multiple Themes**: Choose from System, Light, Dark, Boilerplate, or Cybertron themes
- **Responsive Layout**: Optimized for the Figma plugin window
- **Resizable Panel**: Adjust the plugin width to your preference
- **Data Migration**: Export and import plugin data when needed

## 🚀 Getting Started

### 📦 Installation
1. Open Figma and go to **Plugins > Browse plugins in Community**
2. Search for "stratusHue" and click **Install**

### 📖 Basic Usage

#### 🎨 Adding Color Codes
1. **For Layers**: Select one or more layers to see layer-specific emoji options
2. **For Pages**: Deselect all layers to see page-specific emoji options
3. **Clear Colors**: Use the clear button to remove emojis from selected elements

#### 📅 Adding Dates
1. Click the date button to add today's date
2. With a selection: dates are added to layer names (existing dates are replaced)
3. With no selection: the current page title is updated

#### 🔖 Creating Bookmarks
1. Select any layer you want to bookmark
2. Click the anchor button to drop an anchor
3. Your bookmark will appear in the Anchors list

#### 🧭 Navigating with Bookmarks
1. Click on any bookmark in the list to jump directly to that element
2. The plugin will automatically switch to the correct page and select the element
3. Click the remove button to delete bookmarks you no longer need

#### 🎮 Using Controls
1. Use the Movement & Zoom grid to position elements and navigate the canvas
2. Use the Hierarchy controls to navigate through layer structure
3. Use the Sizing Modes to quickly change auto-layout sizing
